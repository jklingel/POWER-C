conio object library, re-engineered from Borland C
Created by Jan Klingel on 06/30/2026
Version 1.3

As of now includes the following functions:

clrscr(void) 			Clear the screen
setlowercase()			Select the lower/upper character set
setgraphics()			Select the grahics/upper charcater set
int textcolor(char color)	Set the text color. Color codes are defined in conio.h. Returns 0 when valid color value selected, else 1
int framecolor(char color)	Set the frame color. Returns 0 when valid color value selected, else 1
int background(char color)	Set the background color. Returns 0 when valid color value selected, else 1
int gotoxy(char x, char y)	Set the cursor position. Returns 1 if the x or y values are greater than the max number of columns and rows of the screen, else 0
int clearkbbuffer()		Clears the keyboard buffer and returns 0 if successful, otherwise 1
int kbhit()			Returns nonzero if a key has been pressed, else 0

Usage:
  clrscr();
  setlowercase();
  setgraphics();
  textcolor(BROWN);
  framecolor(GREEN);
  background(WHITE);
  gotoxy(5,5);

  int key = 0;
  if (clearkbbuffer() == 0) {
    printf ("Press any key to exit\n");
    while (key == 0) {
      key = kbhit();
    }
  }

Coding:
  Include conio.h in your code:

	#include <conio.h>

Linking:
  When linking the object files, include the conio library:

	$ link -s
	> yourcode.o
	> conio.o
	^
	output file name: yourcode

  You can now exit the shell ('bye') and then load and run your code:

	load "yourcode",9,1
	run
